# Portfólio | Thiago Gonçalves de Barros

Este projeto é uma página pessoal de apresentação profissional.
Ele reúne quem eu sou, as tecnologias que quero aprender, meus projetos
e meu objetivo na área de tecnologia.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

Criar uma página web pessoal para me apresentar profissionalmente,
praticando os conceitos básicos de desenvolvimento web.

## Conteúdo da página

- Apresentação com nome e formação
- Sobre mim
- Tecnologias que quero aprender: Unity, C# e Modelagem 3D
- Meus projetos, com links para os trabalhos que eu desenvolver
- Objetivo profissional
- Links para GitHub, LinkedIn e Instagram

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
